Hiện tại bạn đang có gì?

Hầu hết mọi người đều đã dùng ít nhất 1 trong số này:

  • ChatGPT (OpenAI) — trả phí $20/tháng gói Plus, hoặc $200/tháng gói Pro
  • Claude (Anthropic) — trả phí $20/tháng gói Pro, hoặc $100-200/tháng gói Max
  • Gemini (Google) — miễn phí hoặc có gói Advanced
  • Grok (xAI) — dùng qua X Premium

🤔 Vấn đề là gì?

Mỗi AI giỏi 1 thứ khác nhau — Claude viết hay, GPT code tốt, Gemini tìm kiếm giỏi, Grok cập nhật nhanh. Nhưng bạn phải tự mình nhảy qua nhảy lại giữa các tab, copy-paste kết quả từ con này sang con kia.

⚠️ Hiểu lầm phổ biến

"Dùng API = tốn tiền theo token, rất đắt!" — Đúng nếu mua API key riêng. Nhưng chúng ta không làm vậy.

✅ Cách chúng ta làm: Dùng gói đăng ký (subscription) đã trả

BƯỚC 3.1

Mở Terminal (ứng dụng dòng lệnh)

Terminal là nơi bạn gõ câu lệnh để máy tính thực hiện. Mỗi hệ điều hành có cách mở khác nhau:

  • Mac: Mở app Terminal (tìm trong Spotlight: ⌘+Space, gõ "Terminal")
  • Windows: Mở PowerShell (Start → gõ "PowerShell")
  • Linux: Mở Terminal (Ctrl+Alt+T)
BƯỚC 3.2

Cài CLIProxyAPI

Trên Mac (dùng Homebrew):

# Cài Homebrew trước (nếu chưa có): /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # Cài CLIProxyAPI: brew tap router-for-me/tap brew install cliproxyapi

Trên Linux/Windows (WSL):

# Dùng script cài tự động: curl -fsSL https://raw.githubusercontent.com/router-for-me/CLIProxyAPI/main/scripts/install.sh | bash
📖
Trang chủ CLIProxyAPI: github.com/router-for-me/CLIProxyAPI — xem hướng dẫn đầy đủ và hỗ trợ
BƯỚC 3.3

Đăng nhập tài khoản AI vào CLIProxy

CLIProxy cần bạn đăng nhập 1 lần để lấy "vé" (OAuth token) từ tài khoản đăng ký của bạn:

# Đăng nhập Claude (nếu đang dùng Claude Max/Pro): cliproxyapi --claude-login # → Trình duyệt mở ra, đăng nhập bằng tài khoản Claude của bạn # → Xác nhận quyền truy cập → Xong! # Đăng nhập ChatGPT/Codex (nếu đang dùng OpenAI): cliproxyapi --openai-login # Đăng nhập Gemini (nếu đang dùng Google): cliproxyapi --gemini-login # Đăng nhập Grok (nếu đang dùng xAI): cliproxyapi --grok-login
💡
Đăng nhập bao nhiêu con tuỳ bạn! Có Claude Max + ChatGPT Plus? Đăng nhập cả 2. CLIProxy sẽ tự động phân luồng — khi Claude bận thì dùng GPT.

  • Tạo các kênh (channel) theo ý muốn: #workspace, #research, #code, ...
BƯỚC 5.2

Tạo Bot trên Discord Developer Portal

Mỗi bot AI cần 1 "hộ chiếu" riêng trên Discord. Tạo bao nhiêu bot = lặp lại bấy nhiêu lần.

Truy cập: discord.com/developers/applications

Cho mỗi bot, làm theo thứ tự:

  1. Bấm "New Application" → Đặt tên (VD: "Coordinator")
  2. Vào tab "Bot" bên trái
  3. Bấm "Reset Token" → Copy token ngay (chỉ hiện 1 lần!)
  4. Bật 3 toggle quan trọng ở mục "Privileged Gateway Intents":
    • ✅ Server Members Intent
    • ✅ Message Content Intent
    • ✅ Presence Intent
  5. Vào tab "OAuth2" → chọn scope bot → chọn permissions cần thiết
  6. Copy link invite → Mở link → Chọn server → Authorize
⚠️
Lưu ý bảo mật: Token của bot giống như mật khẩu — không chia sẻ, không đăng lên mạng, không commit vào code. Lưu vào file .env trên máy thôi.

Cấu hình kết nối Discord

Có 2 cách — chọn cách nào bạn thấy dễ hơn:

Cách 1: Dùng wizard (khuyên dùng cho người mới):

hermes gateway setup # → Chọn "Discord" khi được hỏi # → Paste bot token khi được hỏi # → Paste User ID của bạn khi được hỏi

Cách 2: Chỉnh file thủ công (cho người quen Terminal):

# Mở file cấu hình bí mật: nano ~/.hermes/.env # Thêm các dòng sau: DISCORD_BOT_TOKEN=paste-token-bot-ở-đây DISCORD_ALLOWED_USERS=paste-user-id-của-bạn DISCORD_HOME_CHANNEL=paste-id-kênh-chính # Lưu file: Ctrl+X → Y → Enter

Với mỗi bot mới, lặp lại 3 bước:

  1. Tạo Profile: hermes profile create <tên-bot>
  2. Cấu hình AI + Discord: Gán model, bot token, system prompt
  3. Chạy gateway: Tất cả profile chạy cùng lúc
# Ví dụ: Tạo bot Developer dùng GPT hermes profile create developer # Cấu hình profile developer: hermes -p developer setup # → Chọn provider: custom # → Base URL: http://localhost:8317/v1 # → Model: gpt-4o (hoặc model bạn muốn) # Thêm Discord token cho bot developer vào .env: echo "DISCORD_BOT_TOKEN=token-của-bot-developer" >> ~/.hermes/profiles/developer/.env # Chạy tất cả bot cùng lúc: hermes gateway start --all

So sánh: Setup này vs VPS truyền thống Thực chất bạn đang tạo "VPS tại nhà" chuyên cho AI
☁️ VPS truyền thống
  • 💸 Thuê máy ảo trên cloud: $10-50/tháng
  • 🖥️ Cần biết Linux, SSH, dòng lệnh
  • 🔧 Tự cài đặt, bảo trì, cập nhật server
  • ⌨️ Quản lý qua SSH terminal — khó
  • 🌍 Chạy ở data center xa → lag ít
  • 🔌 Không phụ thuộc điện/mạng nhà
🏠 Setup tại nhà (Hermes)
  • 🆓 Dùng máy có sẵn: $0 tiền server
  • 💬 Không cần biết Linux — quản lý qua Discord
  • 🤖 Hermes tự quản lý — ít bảo trì
  • 📱 Quản lý qua Discord/Telegram — dễ
  • 🏠 Chạy tại nhà → phụ thuộc mạng nhà
  • 🔌 Máy tắt = bot offline

✅ Giống nhau — Chạy 24/7 · Truy cập từ xa · Tự động hoá · Nhiều "dịch vụ" cùng lúc

Bản chất: setup này biến máy tính cá nhân thành VPS tại nhà chuyên chạy đội AI. Ai quen VPS sẽ thấy rất quen thuộc!

Ưu điểm & Lưu ý thực tế

✅ Ưu điểm

  • 💰 Tiết kiệm — tận dụng subscription đã trả, không bill bất ngờ
  • 💬 Dễ quản lý — nhắn tin trên Discord như chat bình thường
  • 🔄 Linh hoạt — đổi model AI bất kỳ lúc nào, thêm/bớt bot tuỳ ý
  • 🎯 Chuyên môn hoá — mỗi bot giỏi 1 việc → kết quả tốt hơn
  • 📱 Từ xa — nhắn từ điện thoại qua Discord/Telegram
  • 🔓 Mã nguồn mở — miễn phí, cộng đồng hỗ trợ

⚠️ Lưu ý

  • 🔌 Máy phải chạy liên tục — tắt máy = bot offline
  • 🌐 Internet phải ổn — mất mạng = mất kết nối
  • 📊 Rate limit — subscription có giới hạn, dùng quá nhiều sẽ bị chậm
  • ⏱️ Setup lần đầu — mất 1-2 tiếng cho người mới
  • 🔄 CLIProxy có thể bị chặn — nhà cung cấp AI có thể thay đổi chính sách
  • 🔧 Debug — khi lỗi cần biết đọc log cơ bản
