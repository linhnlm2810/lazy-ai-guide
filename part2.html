CÀI CLIProxyAPI
⚠️ Cần trước: Tài khoản Claude Max/Pro hoặc ChatGPT Plus/Pro đang hoạt động (đã đóng tiền và dùng được bình thường)
3.1
Mở Terminal
🍎 macOS
# Nhấn ⌘ + Space, gõ "Terminal", Enter
🪟 Windows
# Click phải Start → "PowerShell"
🐧 Linux
# Nhấn Ctrl + Alt + T
ℹ️ Terminal là cửa sổ dòng lệnh — nơi bạn gõ lệnh để máy tính thực hiện. Chỉ cần copy-paste là được.
3.2
Cài CLIProxyAPI
🍎 macOS (Homebrew)
brew tap router-for-me/tap brew install cliproxyapi
🐧 Linux / WSL (Windows Subsystem for Linux)
curl -fsSL https://cli-proxy.dev/install.sh | sh
🪟 Windows (không dùng WSL)
# Tải file .exe từ trang GitHub Releases: github.com/router-for-me/CLIProxyAPI/releases # Giải nén → chạy cli-proxy-api.exe
ℹ️ Trang chủ: github.com/router-for-me/CLIProxyAPI — hướng dẫn đầy đủ cho mọi hệ điều hành
3.3
Đăng nhập tài khoản AI — chọn cái bạn đang có
Chỉ cần đăng nhập nhà cung cấp mà bạn đang trả tiền. Không cần đăng nhập tất cả.
🔐 Lưu ý bảo mật QUAN TRỌNG:
  • • Token đăng nhập được lưu tự động trong ~/.cli-proxy-api/ trên máy bạn
  • • KHÔNG BAO GIỜ chia sẻ thư mục này hoặc gửi file trong đó cho ai
  • • KHÔNG upload token lên GitHub, Discord, hay bất kỳ đâu
  • • Ai có token = có quyền dùng tài khoản AI của bạn
🟠 Đang dùng Claude (Max/Pro)?
cliproxyapi --claude-login # Trình duyệt mở ra → đăng nhập # → Xác nhận quyền → Xong!
Gói Max $100/th hoặc Pro $20/th
🟢 Đang dùng ChatGPT (Plus/Pro)?
cliproxyapi --openai-login # Đăng nhập tài khoản OpenAI
Gói Plus $20/th hoặc Pro $200/th
🔵 Đang dùng Gemini?
cliproxyapi --gemini-login # Đăng nhập Google Account
Free hoặc Advanced $20/th
⚡ Đang dùng Grok?
cliproxyapi --grok-login # Đăng nhập tài khoản xAI
X Premium+
ℹ️ Có nhiều AI? Đăng nhập hết. CLIProxy sẽ gộp tất cả lại — khi Claude bận thì tự chuyển sang GPT. Nhưng chỉ cần 1 cái cũng đủ dùng.
3.4
Khởi động CLIProxy
🍎 macOS
brew services start cliproxyapi
🐧 Linux
systemctl --user enable --now cliproxyapi.service
🪟 Windows
# Chạy trực tiếp: cli-proxy-api.exe --config config.yaml
# Kiểm tra xem CLIProxy đã chạy chưa: curl http://localhost:8317/v1/models → {"data": [{"id": "claude-sonnet-4-..."}, ...]} ✅
ℹ️ localhost:8317 là địa chỉ mặc định của CLIProxyAPI — ai cài cũng giống nhau, không phải thông tin riêng. Nó chỉ chạy trên máy bạn, không truy cập được từ bên ngoài.
4
CÀI HERMES AGENT
📋 Cần trước: Terminal đang mở, CLIProxy đang chạy (bước 3.4 OK)
4.1
Cài đặt Hermes Agent
Copy lệnh này vào Terminal và nhấn Enter:
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
4.2
Chạy Setup Wizard
hermes setup
Khi wizard hỏi, chọn:
▸ Provider: chọn "custom / OpenAI-compatible"
▸ Base URL: gõ http://localhost:8317/v1 (mặc định của CLIProxy, ai cài cũng vậy)
▸ API Key: gõ not-needed
▸ Model: chọn theo bảng bên dưới
Nhà cung cấp Tên model gõ vào Ghi chú
Claude claude-sonnet-4-20250514 ⭐ Khuyên dùng
Claude claude-opus-4-20250514 Mạnh nhất, chậm hơn
ChatGPT gpt-4o Nhanh, đa năng
Gemini gemini-2.5-pro Google AI
Grok grok-3 xAI
4.3
Test thử
hermes chat -q 'Xin chào!' → Xin chào! Tôi là Hermes Agent. Rất vui được hỗ trợ bạn! 🎉
✓ Nếu thấy AI trả lời = Hermes đã hoạt động. Bạn đã đi được nửa đường rồi.
5
TẠO DISCORD SERVER & BOT
📋 Cần trước: Tài khoản Discord (đăng ký miễn phí tại discord.com)
5.1
Tạo Discord Server mới
▸ Mở Discord → bấm dấu + bên trái
▸ Chọn "Create My Own" → "For me and my friends"
▸ Đặt tên server (ví dụ: "AI Team Hub")
5.2
Tạo Bot trên Discord Developer Portal
Truy cập:
https://discord.com/developers/applications
❶ Bấm "New Application" → đặt tên bot (VD: "Hermes AI")
❷ Vào tab "Bot" → bấm "Reset Token" → Copy ngay!
❸ Cuộn xuống bật 3 Privileged Gateway Intents:
  • ✓ Presence Intent
  • ✓ Server Members Intent
  • ✓ Message Content Intent
❹ Vào tab "OAuth2" → chọn bot scope → tick các quyền sau:
Quyền Bot cần thiết (Permissions):
✅ Send Messages — gửi tin nhắn
✅ Read Message History — đọc lịch sử
✅ Embed Links — nhúng link
✅ Attach Files — đính kèm file
✅ Use Slash Commands — lệnh /
✅ Add Reactions — thả reaction
✅ Manage Messages — quản lý tin nhắn
✅ Create Public Threads — tạo thread
✅ Send Messages in Threads
✅ Manage Threads
Hoặc chọn Administrator nếu muốn đơn giản — nhưng nên giới hạn quyền cho an toàn.
❺ Copy link mời → mở link → thêm bot vào server bạn vừa tạo
🔐 QUAN TRỌNG: Bot Token chỉ hiện một lần duy nhất! Copy và lưu ngay vào nơi an toàn. Tuyệt đối không chia sẻ token này — ai có token có thể điều khiển bot của bạn.
5.3
Lấy Discord User ID của bạn
▸ Vào Discord Settings → Advanced → bật Developer Mode
▸ Click phải vào tên bạn → "Copy User ID"
👤 User ID là dãy số (VD: 123456789012345678). Hermes dùng ID này để biết ai là "chủ" — chỉ bạn mới ra lệnh được.
6
KẾT NỐI HERMES VỚI DISCORD
📋 Cần trước: Hermes đã cài (bước 4), Bot Token (bước 5.2), User ID (bước 5.3)
6.1
Cấu hình kết nối
Cách 1 — Wizard (khuyên dùng):
hermes gateway setup → Wizard sẽ hỏi Bot Token và User ID — paste vào là xong!
Cách 2 — Thủ công (tạo file .env):
~/.hermes/.env DISCORD_TOKEN=paste-bot-token-ở-đây DISCORD_OWNER_ID=paste-user-id-ở-đây
6.2
Khởi động Gateway
hermes gateway start → 🟢 Gateway connected — Bot is online!
KIỂM TRA KẾT NỐI
Vào Discord server, gõ tin nhắn mention bot:
@Hermes AI Xin chào, bạn có nghe tôi không?
Nếu bot trả lời = xong, hoạt động rồi
Không hoạt động? Kiểm tra:
  • ☐ CLIProxy còn chạy? → curl localhost:8317/v1/models
  • ☐ Bot Token đúng? → Kiểm tra lại Developer Portal
  • ☐ 3 Intents đã bật? → Bot tab → Privileged Intents
  • ☐ Bot đã được mời vào server? → Kiểm tra OAuth2 link
  • ☐ User ID chính xác? → Developer Mode → Copy User ID
