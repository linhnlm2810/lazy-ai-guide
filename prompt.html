Prompt cài đặt tự động

Copy prompt bên dưới, paste vào AI — để nó hướng dẫn hoặc tự cài hết cho bạn.

Agent Mode

Dùng khi bạn có AI agent chạy trên terminal — Claude Code, Codex, hoặc Hermes. Paste prompt vào, agent sẽ tự chạy lệnh cài đặt. Bạn chỉ cần trả lời vài câu hỏi và làm phần Discord thủ công.

Guide Mode

Dùng khi bạn chat với AI trên web — ChatGPT, Claude.ai, Gemini. Paste prompt vào, AI sẽ hướng dẫn bạn từng bước với lệnh copy-paste. Bạn tự chạy lệnh, AI chỉ hướng dẫn.
