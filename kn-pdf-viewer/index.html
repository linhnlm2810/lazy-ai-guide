Kỹ năng Claude cho xem và ký PDF: cách cài và cách gọi

Plugin pdf-viewer của Anthropic: mở PDF, tô sáng, điền biểu mẫu, đặt chữ ký hình. Cách cài trên Cowork, Claude Code và cách gọi 1 kỹ năng, 4 lệnh.

xem và ký PDF1 kỹ năngCách cài

Nhiều công việc văn phòng xoay quanh một file PDF: đọc hợp đồng, đánh dấu chỗ cần sửa, điền biểu mẫu, đóng dấu duyệt, ký. Nhóm kỹ năng pdf-viewer của Anthropic mở PDF trong một khung xem trực tiếp, để Claude và các bạn cùng nhìn một trang, cùng chỉnh, rồi tải bản đã đánh dấu về.

Plugin pdf-viewer có 1 kỹ năng (view-pdf) và 4 lệnh (open, annotate, fill-form, sign). Chúng mình đếm từ thư mục skills và commands của kho gốc.

Cài đặt

Cách 1: Claude Cowork

  1. NGƯỜI: vào claude.com/plugins và cài plugin pdf-viewer. README gốc hướng dẫn cài plugin cho Cowork ở trang này.

Cách 2: Claude Code

  1. NGƯỜI: mở terminal, chạy hai lệnh sau, chép đúng từ README của kho gốc. Lệnh đầu thêm kho plugin của Anthropic, lệnh thứ hai cài nhóm xem PDF. 
    claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install pdf-viewer@knowledge-work-plugins
  2. TỰ ĐỘNG: sau khi cài, plugin tự kích hoạt. Theo README gốc, kỹ năng tự chạy khi đúng việc và lệnh gõ tắt dùng được ngay trong phiên làm việc. Máy chủ PDF cũng tự khởi động khi plugin được nạp, chạy trên máy của các bạn qua npx.
  3. NGƯỜI: kiểm đã cài chưa. Gõ /plugin, mở thẻ Installed và tìm pdf-viewer.
  4. NGƯỜI: chuẩn bị máy. Plugin cần Node.js phiên bản 18 trở lên. Muốn mở PDF từ mạng (arXiv và các nguồn khác) thì máy cần có Internet.

Muốn tắt hoặc gỡ plugin, chạy một trong hai lệnh sau:

claude plugin disable pdf-viewer@knowledge-work-plugins
claude plugin uninstall pdf-viewer@knowledge-work-plugins

Nối công cụ: nhóm này không cần nối dịch vụ ngoài. CONNECTORS.md ghi plugin dùng một máy chủ cục bộ @modelcontextprotocol/server-pdf, không cần khóa API hay đăng nhập.

Cách gọi kỹ năng

Có hai cách, theo README gốc và Docs của Claude Code.

  1. Nói việc bằng lời thường. Kỹ năng tự chạy khi đúng việc. Ví dụ: "Mở hợp đồng này cho mình xem và tô các điều khoản về chấm dứt".
  2. Gọi thẳng bằng lệnh gõ tắt dạng /pdf-viewer:<tên>. Các lệnh của plugin này nhận một đối số là đường dẫn file hoặc link PDF (theo gợi ý đối số trong file lệnh). Ví dụ: 
    /pdf-viewer:open hop-dong-thue.pdf
/pdf-viewer:annotate hop-dong-thue.pdf
/pdf-viewer:sign don-xin-viec.pdf chu-ky.png

Lưu ý từ README: plugin dành cho việc cần nhìn và chỉnh trực quan. Nếu các bạn chỉ cần tóm tắt hoặc trích chữ từ PDF, đừng mở khung xem. Claude đọc thẳng file PDF được và làm việc đó nhanh hơn.

Các kỹ năng trong nhóm

  • /pdf-viewer:view-pdf: khung xem PDF tương tác. Dùng khi các bạn muốn mở, xem PDF và cùng Claude làm việc trực quan: tô sáng, đóng dấu, điền biểu mẫu, đặt chữ ký hoặc chữ viết tắt, xem lại các đánh dấu. Không dùng để tóm tắt hay trích chữ. Câu gọi mẫu: "Mở file hợp đồng này, tô các điều khoản quan trọng để mình xem lại."

Lệnh

  • /pdf-viewer:open: mở một PDF trong khung xem, từ file trên máy hoặc link PDF trực tiếp. Chưa đưa đường dẫn thì Claude liệt kê các PDF có sẵn. Câu gọi mẫu: "Mở giúp mình file bao-cao-quy-3.pdf."
  • /pdf-viewer:annotate: cùng đọc tài liệu, Claude đề xuất đánh dấu từng đoạn, các bạn duyệt từng đợt trong khung xem rồi mới đi tiếp. Có tô sáng, gạch chân, gạch ngang, ghi chú, hộp chữ, hình khối và con dấu như APPROVED, DRAFT, CONFIDENTIAL. Câu gọi mẫu: "Đọc hợp đồng này và đề xuất chỗ cần tô sáng, ghi chú. Mình duyệt từng đợt."
  • /pdf-viewer:fill-form: điền biểu mẫu PDF có ô nhập, thấy kết quả ngay trên trang. Với biểu mẫu có tên ô khó hiểu, Claude chụp trang để biết nhãn in cạnh mỗi ô rồi mới điền. Câu gọi mẫu: "Giúp mình điền tờ khai này, ô nào chưa rõ thì hỏi mình."
  • /pdf-viewer:sign: đặt ảnh chữ ký hoặc chữ viết tắt lên trang PDF. Các bạn cần có sẵn ảnh chữ ký dạng PNG hoặc JPG. Câu gọi mẫu: "Đặt chữ ký trong file chu-ky.png vào góc dưới bên phải trang 3."

Điền xong và đánh dấu xong, các bạn tải bản PDF đã chỉnh từ thanh công cụ của khung xem.

Lưu ý khi dùng ở Việt Nam

  • Theo README, /pdf-viewer:sign chỉ đặt ảnh chữ ký lên trang. Đó không phải chữ ký số có chứng thực hay mã hóa. Văn bản cần giá trị pháp lý bằng chữ ký điện tử thì dùng dịch vụ ký chuyên dụng.
  • Nhận xét của chúng mình: biểu mẫu hành chính trong nước hay là bản scan, không có ô nhập. Khi đó /pdf-viewer:fill-form không có ô để điền. Việc đặt chữ và ảnh lên trang dùng /pdf-viewer:annotate và /pdf-viewer:sign.
  • Chỉ mở file có đường dẫn nằm trong thư mục làm việc của các bạn, hoặc link PDF trực tiếp. Link tới trang giới thiệu (không phải file PDF) thì README nói là không mở được.
  • Tài liệu nội bộ hoặc có thông tin cá nhân: nội dung trang được đưa cho Claude đọc khi đánh dấu. Các bạn cân nhắc theo quy định của tổ chức mình trước khi mở.

Chúng mình chưa cài thử nhóm này; lệnh và tên kỹ năng lấy từ kho gốc của Anthropic.
